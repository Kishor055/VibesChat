
# PulseTalk | Cosmic Real-Time Communication

PulseTalk is an enterprise-grade, real-time messaging platform designed with a modern cosmic aesthetic and AI-driven features. Built with Next.js, Firebase, and Genkit, it offers a high-performance communication experience with zero-friction access.

## 🚀 Key Features

- **Real-Time Communication**: Instant message delivery powered by Google Cloud Firestore.
- **AI Smart Replies**: Context-aware message suggestions generated by Google Gemini 2.5 Flash via Genkit.
- **Glassmorphism UI**: A premium, high-fidelity visual interface built with Tailwind CSS and Shadcn UI.
- **Zero-Friction Access**: Persistent Guest Identity system for immediate platform exploration.
- **Responsive Architecture**: Fluid design optimized for desktop and mobile environments.
- **Cosmic Aesthetics**: Dynamic backgrounds and high-quality placeholder imagery.

## 🛠 Tech Stack

- **Frontend**: Next.js 15 (App Router), React 19, TypeScript
- **Styling**: Tailwind CSS, Framer Motion, Lucide Icons
- **Backend/Database**: Firebase Firestore, Firebase Authentication
- **AI Logic**: Genkit v1.x with Google Gemini 2.5 Flash
- **Components**: Shadcn UI (Radix UI primitives)

## 📁 Architecture Overview

```text
src/
├── ai/              # Genkit AI flows and prompt definitions
├── app/             # Next.js App Router pages and layouts
├── components/      # Modular UI components (Chat, Common, UI)
├── firebase/        # Firebase initialization and SDK hooks
├── hooks/           # Custom React hooks (Auth, Presence)
├── lib/             # Utility functions and shared constants
└── styles/          # Global styles and Tailwind configurations
```

## 🔒 Security & Reliability

- **Hydration Safety**: Advanced mounting strategies prevent React hydration mismatches.
- **Data Integrity**: Optimized Firestore queries with client-side optimistic updates.
- **Error Handling**: Centralized error emitter system for graceful failure recovery.

## 🛠 Getting Started

1. **Environment Config**: Ensure `NEXT_PUBLIC_FIREBASE_PROJECT_ID` is set in your environment.
2. **AI Integration**: Genkit flows are located in `src/ai/flows`.
3. **Run Development**: `npm run dev` to start the local environment.

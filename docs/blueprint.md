# **App Name**: PulseTalk

## Core Features:

- Hybrid Auth Gateway: Secure multi-provider authentication using Firebase for social logins and custom JWT tokens for session management.
- Instant Message Broadcast: Low-latency real-time private messaging using Socket.IO events for instantaneous communication delivery.
- Smart Reply Assistant: A feature that uses a generative AI tool to analyze conversation context and suggest relevant quick-responses for users.
- Channel Room Architecture: Enables group communication with dedicated rooms, member administration, and persistence in MongoDB.
- Real-Time Presence: Visual online/offline indicators and active typing animations handled via persistent WebSocket connections.
- Chat Archive Hub: Permanent message storage with optimized MongoDB schemas for rapid historical search and retrieval.
- Glassmorphic Workspace: A high-end, responsive Next.js dashboard featuring blurred glass textures and adaptive dark/light modes.

## Style Guidelines:

- The 'Cosmic Connectivity' theme features a Primary Purple (#7C3AED) evoking modern tech energy, set against a deeply desaturated Indigo-Black background (#0D0B14).
- An Analogous Accent color of Steel Blue (#94ACFF) is utilized for active states and subtle highlights, ensuring high-contrast clarity.
- Body and Headline font: 'Inter'. This choice reflects an objective, machined, and neutral aesthetic suitable for high-speed communication. (Note: currently only Google Fonts are supported.)
- The interface uses a multi-panel layout with fixed sidebars and glassmorphic message containers, following professional mobile-first grid standards.
- Minimalist, thin-stroke Lucide-react icons used sparingly to maintain focus on textual communication.
- Frammer Motion is used for smooth spring-based message entrance transitions and real-time status fade-ins.
